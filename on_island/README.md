# On Island

This is an experimental island survival game; some features are incomplete.

Contributes are welcome.

Currently we only have Simplified Chinese translation, without English.

---

这是一个孤岛生存游戏，目前仍处于实验阶段，部分功能不完备。

欢迎贡献。

目前只有中文翻译，没有英文。

## 操作

游戏从标题界面开始，按 `Enter` 或空格进入游戏，`Esc` 返回标题界面。按 `$` 可在各主界面打开选项；选项包括方位显示（相对、绝对或两者）。

- `[x]` 检查自身
- `[l]` 观察周围：统一查看地点、书签、地物/生物、合成表面、地面物品、可采集资源与可开采地表。同类对象会合并，`←/→` 按距离切换合并项，切换后该组会移动到对应距离的位置并保留所选的合并项；`c` 即时开关合并，关闭合并后 `←/→` 仍会跳到同类条目。`d` 按当前方位显示方式过滤（两者时取相对方位）。所有目标的位置统一显示为`方向，距离米`（如`前，4米`），与自身重合或包含自身的对象显示为`中，0米`。列表内无修饰键执行所选对象的操作（如 `l` 查看、`t` 前往、`p` 拾取、`h` 手持、`w` 穿戴、`g` 采集、`n` 开采），界面底部显示当前对象的全部操作键；`Shift+类别键` 切换类别过滤，`Alt+类别键` 只显示该类别，`Shift+F` 快捷攻击。`m` 在观察/移动模式之间切换。
- `[i]` 物品栏：与观察周围使用相同的 `[序号][类别]` 前缀、索引行和底部布局。合并使用、穿戴与周围物品。无修饰键执行所选对象的操作（`u` 使用、`w` 穿戴/脱下、`h` 手持、`p` 拾取、`l` 查看），界面底部显示全部操作键；`Enter` 执行默认交互；`Shift+i/w/p/u` 过滤背包、穿戴、周围物品或仅可用物品，`Alt+i/w/p/u` 只显示该类别。背包放不下时，拾取和脱下的物品会先拿在手上，双手也放不下时才放在地上。
- `[m]` 移动/旋转：直接进入观察周围的移动模式。`←/→` 转向，`↑/↓` 调整俯仰，`WASD` 移动，`+`/`-` 调整步长；移动时仍显示周围的参照物，但只显示前方半球，后方对象需要手动转向才能看见。
- `[f]` 战斗：持续战斗界面，攻击后返回战斗界面，`Esc` 退出。
- `[r]` 休息：休息与睡觉合并为一个界面；精神充沛时无法入睡。
- `[j]` 日志：每条记录显示游戏时间；`←/→` 在相同消息的不同时间之间切换，效果类似观察周围的合并项切换；`c` 即时开关合并。主界面底部显示最近三条。
- `[c]` 合成、`[q]` 退出。
- 列表支持 `Ctrl+↑/↓` 快速滚动 5 项。

## 信息获取

**角色的信息不是全知的：没有对应能力或物品，就不能获得相应信息。**

- 方位：默认显示相对方位（前/左前/…）。没有指南针时只显示八方位文字；持有指南针才会显示精确到度的方位。可在选项中切换为绝对方位或同时显示两者。
- 温度：没有温度计不能获知气温；持有温度计时才会在主界面和检查自身时显示气温与体温。
- 绝对坐标：只有 `src/main.rs` 中的调试常量 `DEBUG` 为 `true` 时才允许显示；正常界面只显示相对于坐标原点的位置。
- 感知只影响已有信息的精度，不能替代指南针、温度计等物品。
- 指南针、温度计等物品都遵循“先取得对应功能，再显示对应信息”的原则；后续信息也按此原则补齐。

## 技术细节

使用Rust语言。项目具有相当实验性，使用了nightly的const相关特性开关。

目前使用常量/static函数接口，不支持动态数据加载，且为单线程。

地形由 `world::shape`（形状）、`world::material`（材质）、`world::terrain`（颗粒与聚合体）、`world::spatial`（包围盒网格索引）构成。

游戏时间精确至us，默认10ms为一刻，可在选项中调整每tick模拟的游戏时间间隔。在行动确定后时间才会流逝。

世界使用三维坐标，按生物群系生成资源和生物；实体资源由世界统一管理。

地形不是体素网格，而是由三维浮点形状（球、椭球、圆柱、凸包、任意三角网格）组成的颗粒模型：

- 每个颗粒是一个闭合形状，装且只装一种材质；同一位置可以自由重叠多个材质颗粒。
- 采样一个点会得到该处所有材质的体积占比（例如 `土壤 70%、砾石 20%、碎石 10%`），重叠部分按占比计。
- 每个材质是一个独立模型，拥有自己的颗粒形状风格、持水性、开采硬度与产出物品，定义在 `world::material`。
- 聚合体（树木、救生艇、水体、地表）是由颗粒组成的 `Body`，可被查看、采集、开采与浇水。
- 移动碰撞使用胶囊对形状的精确查询，而不是方块判定。

地形按 1m² 的单元格生成，每格可容纳多种材质的颗粒，颗粒厚度与材质占比成正比；地表资源可通过开采动作按占比取出成物品。

玩家的疲劳会随活动累积、在休息时恢复，并降低行动效率、移动/交互/视距与负重能力，同时增加能量和水分消耗。感知决定数值与角度的显示精度，不会增加视距。


## 基准测试

性能基准分为 tick 吞吐与各世界子系统开销，需在 release 下运行：

```sh
cargo test --release game::bench -- --ignored --nocapture
cargo test --release world::bench -- --ignored --nocapture
```

## 路线图

设计为尽可能真实，并将在稳定后添加超现实内容。

按以下优先级推进；每阶段以可重复验证的游戏行为和自动化测试作为完成标准。

1. **打通可玩流程**：完善新游戏、菜单、物品栏与行动反馈，确保玩家能从开局完成采集、制作、旅行、休息直到明确的游戏结束状态。
2. **扩展生存内容**：逐步实现环境影响、伤害与生物交互，并使食物、水源和装备形成可平衡的生存循环。
