# 混乱擢升

这是一个终端文字冒险游戏。

地球及其三光年内的区域被复制到了异界。你作为一个玩家，需要在越来越扭曲的世界里生存。

## 设定

### 世界观

- 扭曲值：随时间推移不断上升，出现各种异变。
  实质（能量、物质、超凡能量的总称）
- 扭曲能：所有能量的来源（暂不实现，在大后期出现）。
- 魂（soul）：能够用于构成复杂意识的高可控能量。
- 灵（psychic）：通过思想/意识能够控制的能量，也能带动其他能量。
  - 会被魂影响；被意志、信念、精神属性增幅。
- 法（magic）：可以储备，用来释放魔法或制造魔法装备和道具。

### 玩家

- 玩家相当于控制人类躯体的意识，身体状态会影响操控效率。
- 玩家可以选择初始属性和位置（城市/乡村/无人区）

## 技术细节

- 数据驱动，支持json5，存储二进制缓存。
- 游戏内自带关于物品/生物的档案，接触解锁（例如对方释放相应的技能）。
- 物品/生物属性随机浮动。
- 所有数据可调。例如扭曲值有一个增量，增量线性增长（二次增长，增量不断变大）。初始扭曲值、扭曲值增量、扭曲值增量的增量都可调整。玩家和生物数据也可调整。
- 人类（包括玩家）有基本的情绪、意向，八大系统（运动、消化、呼吸、循环、泌尿、神经、内分泌和生殖系统），还有状态和属性（例如*饥饿*导致*力量*降低和*移动速度*降低，*疲倦*导致*思维速度*和*反应速度*降低）。
- 游戏**尽可能真实**。例如怪物不掉落装备，而是掉落他们自身的尸体，可以肢解提炼材料等。

## 演变

世界内的所有东西都会逐渐扭曲，拥有超能。

### 1阶段（初始）

#### 背景

人类发现精密仪器出现误差，宇宙震荡和一些无规律的外星信号。

#### 生物

- 人类：看起来是人也保持人性的生物。其实就是人。

### 2阶段

#### 背景

开展科学研究，尝试制造丧尸病毒的疫苗和解剂，发现「魂」「灵」「法」，有相关的故事，但除了部分属性增幅外没发现什么用。

#### 生物

- 丧尸：被丧尸病毒感染后的人，思维混沌。
  - 丧尸首领：逐渐从丧尸群中诞生的有意识的丧尸，可以聚集其他丧尸干一些基本活动。不一定是敌对的。
- 药草：不同的药草，能治愈/补充超凡能量。

### 3阶段

#### 背景

电力、网络和人工智能开始失常。

#### 生物

有一些生物会进行色情攻击。

- 人类：人类开始能够用意识控制「法」或拿来制造装备。
- 僵尸：人死后化为的不死生物，没有意识，靠本能行动。
  - 有魂尸：有魂魄的僵尸。有意识智能。
- 魂魄：人死后的灵魂。
- 黏液怪：类似史莱姆的黏糊糊的怪物。有不同的体型，可以合并或分裂，被切开也会分裂，分裂在分开的同时会扣除生命值。
- 触手怪：招式繁多的怪物，会缠绕、抽打和突进。
- 藤蔓怪：≈植物系触手怪。
  - 荆棘怪：≈长刺的藤蔓怪。
