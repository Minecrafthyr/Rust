## 上手指南

### 界面

主界面从上到下依次是：

1. **状态行**：游戏时间、当前阶段、当前模式、扭曲值。
2. **所在地**：地点名称与区域、已探索百分比（`?` 可能刷新、`!` 档案确认必然刷新）、已发现地点数。
3. **状态与威胁**：正常、被追击或被拘留；遇到敌人时显示其名称与生命条，否则显示「威胁：无」。
4. **身体**：当前躯体与地上的尸体、生命、饥饿、疲倦、口渴、尿意、便意。
5. **资源**：灵、法、魂、感染、武器、防具。
6. **日志**：带时间、重要程度（`·` 细节、`!` 重要、`#` 关键）和类别，关键日志为红色加粗。
7. **底部提示**：当前模式下可用的按键，包括潜入路线与领救济粮。

战斗时日志缩到上半屏，下半屏变成行动面板。

### 提示

- 角色会自己行动；你的主要工作是**观察**。日志里的事件顺序、地点描述和档案内容会逐渐拼出世界在发生什么。
- 觉得演算太快时按 `[空格]` 暂停，再按 `[↑]` 回看日志。
- 设置里的「演算延迟」为 `0` 时推进最快，适合只想看结果。
