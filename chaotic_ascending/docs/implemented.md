# 已实现内容

本文是从 README 拆分出来的详细实现清单，随内容数据更新。数值与条目可在 `data/content/` 中调整；结构与数据格式见 [技术细节](technical.md)，世界观见 [阶段演变](evolution.md)。

## 循环、模式与转生

- **全自动**：角色自动搜索、休息、移动和战斗；强敌出现时暂停并交给玩家。
- **半自动**：日常行动由玩家选择，普通战斗自动结算，强敌和手动模式下的战斗由玩家指挥。
- **手动**：日常行动和全部战斗都由玩家操作。
- **第一循环**只开放全自动，角色也不会主动搜集装备、物资和机密情报。第一次结算界面会永久解锁半自动/手动模式。
- 循环次数达到 5 次后，可以转入档案里**见过的人类**躯体。人类宿主会带来对应的通行权限，例如研究员、逃兵和政府守卫。
- 也可以拒绝转移。拒绝不会阻止继续游玩，只是更难接触机密地点。
- 第四阶段之后，新循环可以选择从**第二阶段或第三阶段**开始，也可以继续当前阶段。
- 第四阶段后，还能转入**解剖过的类脑怪物**躯体；该怪物必须出现在所选起始阶段或更早。
- 击败生物会留下尸体。半自动/手动模式用 `[d]` 解剖，自动模式在角色有意识（档案中的「意识」开启）时会主动解剖。解剖结果永久写入档案。

## 需求与设施

- 饥饿、口渴、疲倦、尿意和便意分别按小时累积。
- 主界面、状态面板和结算界面都会显示排便相关数据；便意过高时会损害健康并削弱消化系统。
- 城市与乡村地点默认有厕所，地图用 `[T]` 标记；无人区地点没有厕所。
- 在无人区如厕时，角色会在远离水源和营地的背风处就地解决。
- 数据字段：地点可显式设置 `toilet: true/false`；未设置时城市/乡村为有厕所，无人区为无厕所。

## 地点

- 城市：废弃公寓、河湾公寓、波士顿公立学校、港湾超市、联排民宅、街角便利店、社区药房、圣玛丽医院、官方接种点、警察局、波士顿看守所、南站、剑桥大学区、购物中心、地铁隧道、碧落研究园区。
- 乡村：边境农场、白篱笆民宅、林间木屋、乡道便利店、公路加油站、乡村杂货店、乡村诊所、林间药草地、山脊广播塔。
- 无人区：国家森林、幸存者营地、废弃采石场、军事检查站、地下实验室。
- 随机地点：14 个带门牌号/店名的民宅与商店，资源表由种子生成，循环后保持一致。

地点有危险度、封锁阶段、搜索次数、连接、厕所和按阶段过滤的战利品表。学校、公寓、超市、便利店和民宅都填入了对应的现实物资；前两天的物资数量约为平时的三倍，且一条潜入路线一次可取得多类物品。超市、便利店、杂货店和部分民宅会刷新物资，探索界面用 `?`/`!` 标记。

研究园区、检查站和地下实验室包含「碧落计划」线索。地下实验室、研究园区、采石场和国家森林在第四阶段会产出游离之法、法杖或聚法晶体。

### 探索、潜入与拘留

- 探索进度以百分比显示，由已使用搜索次数/总搜索次数计算。
- `?` 表示可能刷新，`!` 表示档案已确认必然刷新（通常来自上一次循环）。
- 在有人的地点取物会被目击并触发追击。追击中按敏捷、感知和疲劳判定逃脱；连续失败三次会被拘留。
- 潜入路线由地点数据控制：`vent`（通风口）、`back_door`（后门）、`fire_escape`（消防通道）。通风口最安全，后门在夜间更安全。
- 被拘留会没收赃物并移动到看守所，第二天自动获释；拘留期间所有行动变为等待。
- 学校、接种点、农场、杂货店和幸存者营地有救济粮，每天一次，直到第 7 天。

## 生物

- 第一阶段：幸存者、徒步者、流浪犬、鼠群、掠夺者。
- 第二阶段：丧尸、丧尸首领、尸群暴君、感染鹿、逃兵、黏液怪、触手怪、藤蔓怪、荆棘怪、药草精、研究员。
- 第三阶段（小型变异为主）：魂魄、有魂尸、觉醒者、法徒、灵猎手、血肉团块、荧光苔、捕蝇蕨、孢囊菇、种子行者、双头乌鸦、七足兔、玻璃浣熊、低语蛾。
- 第四阶段：法主、食法者、虚空猎犬、现实之花、魂骸巨像、游离法灵，以及从第三阶段移入的黏液之王、触手恐魔、荆棘母株、扭曲化身。
- 政府守卫：封锁机密地点，没有权限时无法正面突破。
- 生物生命和伤害生成时有 ±15% 浮动；掉落尸体材料。
- 数据字段：`human` 标记可作为人类宿主；`brain` 标记具有类脑结构、可解剖并作为怪物宿主。

## 技能

- 本能：腐化撕咬、分裂、触手抽打、藤蔓缠绕、荆棘爆发、酸液喷吐。
- 魂：魂啸、摄魂、精神爱抚（日志只记录名称）。
- 灵/法：法弹、灵能推击、扭曲脉冲、安神微光。

技能在生物使用时记录；第三阶段且资源足够时可重现。

## 第四阶段与法

- 第四阶段从第 180 天开始（默认扭曲阈值 341）；没有终局阈值，扭曲和数值会继续增长，界面标记为 WIP。
- 进入第四阶段时，游离的法凝结为可收集的光尘，角色获得灵、法、魂；随时间经过也会偶尔从空气中收拢 1 点法。
- 新物品「游离之法」可从第四阶段地点和怪物身上取得。
- 白蜡法杖和扭曲仪式杖是武器，同时提供法术伤害加成。
- 聚法晶体作为魔法设备出现，为后续法器制作与仪式系统保留数据入口。
- 第四阶段解锁阶段重演和怪物宿主资格。

## 档案与数据

- 档案记录生物、物品、地点、技能、解剖状态、循环次数、模式解锁、第四阶段记忆、地点记忆、渗透进度和关键情报。
- **纪事**跨循环记录阶段变化、死亡、拘留、重大情报、假情报与弱点报告。
- 每个档案条目记录**情报来源**，可累积多个信源。
- **情报栏**按身份卡、地图、纸条、网络、传闻、其他分类折叠，按重要程度排序；详见二级页面。模糊情报在核实后只确认一部分，假情报只有在对应地点搜查无果后才标记为假。
- **人物**页记录 NPC 属性、角色、关系、相遇次数和他告诉你的情报，需从档案主菜单手动进入二级页面。
- **弱点报告**存入生物档案，来源包括网络公告、研究设施数据库（身份卡 + 数据库密码）、反复攻击和解剖。
- 存档版本随字段变更递增；旧版本世界存档会被拒绝加载。
- 内容校验会检查生物引用的技能与材料、弱点对应生物、情报指向地点、NPC/地点引用情报、地点链接的双向性、战利品物品和起始地点。
