# 玩法系统

## 三种模式

角色默认由程序驱动，玩家像观察一场实验一样看它行动。三种模式决定你介入的深浅：

| 模式 | 日常行动 | 战斗 |
| --- | --- | --- |
| 全自动 | 角色自行搜索、休息、移动 | 角色自行战斗；强敌出现时暂停并交给玩家 |
| 半自动 | 玩家逐次选择，每次行动后显示结果 | 普通战斗由角色自动结算，强敌由玩家指挥 |
| 手动 | 玩家逐次选择 | 所有战斗都由玩家操作 |

半自动模式下的行动结果（物资、敌人、情报）只显示在屏幕上，不写入日志，方便玩家自己判断下一步。

按 `[Tab]` 在已解锁的模式之间循环；自动模式下 `[空格]` 暂停/继续，暂停时 `[.]` 单步。演算延迟可调，调到 `0` 时每帧批量推进多个行动，但模型仍然逐步计算。

## 循环与意识

一局游戏由多次「循环」组成：角色死亡时本次循环结束，随后可以在同一个世界里开始下一次循环。第四阶段之后世界不会结束，扭曲值会继续增长（WIP）。

- **时间与档案不重置**：新循环开始时，游戏时间、扭曲值和世界状态继续推进，地图、地点档案、技能、情报和权限都保留。角色只带走记忆，从起点重新出发。
- **第一循环没有自觉**：角色只想活着，不会主动搜集武器、装备和机密情报，也不会监控网络或进入机密地点。
- **第一次循环结束的结算界面**会提示并永久解锁半自动/手动模式。此后可以按 `[Tab]` 切换模式。
- **意识**在「不是第一循环」的前提下、第一次进入第二阶段（或更晚阶段）时开启。开启后，之后的循环会正常搜寻和装备物资、监控网络与尝试进入机密地点。

## 时间与需求

时间和需求都在模型里逐分钟推进，而不是用长时间跳跃掩盖。

| 行动 | 耗时 |
| --- | --- |
| 搜索 | 15 分钟 |
| 潜入取物（通风口/后门/消防通道） | 15–30 分钟 |
| 领救济粮 | 10 分钟 |
| 护理（进食、饮水、如厕、治疗） | 5 分钟 |
| 休息 | 60 分钟 |
| 网络监控 | 60 分钟 |
| 潜入 | 120 分钟 |
| 移动 | 由地图距离、人流与拥堵计算 |
| 战斗回合 | 0.1 秒 |

所有行动都带十分之一秒的抖动，因此时钟很少正好落在整分钟。

需求按小时累积：

- 饥饿、口渴、疲倦、**尿意**、**便意**。
- 默认一天内会出现多次进食、饮水、如厕和休息。
- 长时间憋便会在超过阈值后损害健康；尿意与便意还会分别削弱泌尿系统和消化系统，便意也会拖慢敏捷。

**厕所**：

- 城市与乡村地点有厕所，如厕会同时解决尿意和便意。
- 无人区没有厕所，角色会在远离水源和营地的背风处就地解决。
- 被拘留时所有行动都会变成「等待」，直到第二天获释。
- 主界面显示「厕所 可用/就地解决」，地图面板用 `[T]` 标记有厕所的地点。

## 搜索、潜入与被拘留

- 地点用**百分比**表示大致探索程度；`?` 表示这里可能刷新物资，`!` 表示跨循环档案已经确认它必然刷新。
- 第 1–2 天城市与乡村仍有大量现实品类的物资，超市、学校、公寓和民宅的货架远没有搬空。
- 在有人看守/有人居住的地点拿走物资可能被目击。被目击会触发追击；追击中靠敏捷与感知尝试摆脱，失败会被拘留。
- 潜入路线：`[v]` 钻通风口、`[k]` 走后门（夜间/无人时更安全）、`[x]` 走大楼消防通道。路线是否存在取决于地点。
- 被拘留会交出赃物，被带到看守所，并在第二天离开；拘留期间只能等待。
- 有救济粮的地点按 `[g]` 领取，每天一次，持续到第 7 天。救济粮不需要潜入，也不会触发追击。

## 二维世界

世界是一张 64×32 的地图，每个地点有固定坐标，随机民宅/商店也由种子定位。

- 人口按时间段形成通勤流量，早晚高峰的主路会拥堵；移动耗时随距离和拥堵增加。
- 地图面板用 `[·/░/▒/▓]` 表示人流与拥堵，`[z]` 表示高感染地点，`[T]` 表示带厕所的地点，`[!]` 表示机密地点。
- 感染沿人流路线传播，感染高的地点更容易遇到感染者；之后拥堵与感染还会积累动乱。
- 地图每小时更新一次，战斗和日常事件则保持更细粒度。

## 转生、解剖与阶段重演

> 本节是核心剧透。

- **转生**：第 5 次循环起，角色发现自己能沿着见过的面孔，转入他人体内开始循环。只要档案里见过某个人类，就能在新循环选择其作为躯体。
- **拒绝转移**：也可以出于个人道德拒绝转移。不转移不会阻止继续游玩，只是更难接触机密地点——人类宿主会带来对应的社会权限，例如研究员、逃兵或政府守卫的通行资格。
- **解剖**：击败生物后会留下尸体。半自动/手动模式按 `[d]` 解剖，自动演算在角色有意识（档案中的「意识」开启）后也会主动解剖。解剖结果永久写入档案，档案里会标明该生物是否有类脑结构。
- **怪物宿主**：第四阶段后可以转入怪物躯体，但必须同时满足——具有类脑结构、已被解剖、出现阶段不晚于本次循环的起始阶段。
- **阶段重演**：第四阶段之后，新循环可以选择从第二阶段或第三阶段开始（或者继续当前阶段）。重建的阶段只改变扭曲值，档案和时间线保持。
- 转移只在新循环开始时进行；进入循环后无法中途换躯。

## 档案与循环

- 接触生物、物品、地点时解锁档案；生物使用技能时记录技能。选中条目会标明**情报来源**，同一信息可以有多个来源。
- 档案新增**纪事**，只收录世界的既定历史轨迹（预定义背景），不记录角色做过什么。每条纪事要在对应日期之后达成条件才会解锁：到达相关地点（研究中心、天文台、接种点、封锁线等）、看到相关生物、获知相关新闻、听到广播、正在用电、得到通知、看见异空间或取得研究记录；未解锁条目只显示日期和条件提示。
- 档案新增**情报栏**，按身份卡/地图/纸条/网络/传闻/其他折叠，并按重要程度排序；详情写在二级页面。
- 档案新增**人物**：记录 NPC 属性、相遇次数和他告诉你的情报，需要从档案主菜单手动进入。
- 生物档案新增**弱点报告**：可从网络公告、研究设施数据库（需要身份卡和数据库密码）、反复攻击或解剖获知；报告写在对应生物的子页面，不进入纪事。
- 档案新增**事件**，跨循环记录循环开始与结束、阶段变化、拘留、重大情报与假情报。弱点报告不会重复写入纪事或事件。
- 情报可能是模糊的；机密情报还可能是假的。只有抵达对应地点并实际搜查、发现什么也没有后，才会显式标记为「假情报」。
- 地点只有**实际抵达**后才显示描述；只通过线索得知的地点只显示名称和得知时的阶段。
- 跨循环保留：技能、地点记忆、守卫接触次数、关键情报、潜入权限、循环次数、模式解锁、解剖记录、阶段记忆、事件、人物关系、弱点报告、情报状态和纪事解锁状态。纪事正文来自预定义内容，解锁状态与触发标记写入档案。

结束本次循环的结算界面统计用时、发现/到访地点、搜索、击杀、物资、情报、路程、用餐、饮水、如厕、排便、解剖和休息次数，然后按 `[n]` 开始新循环、`[q]` 保存并退出。

## 发现地点

新地点可以通过以下方式发现：

1. 在当前地点探索，随机发现邻近地点或随机民宅/商店。
2. 与友善 NPC 交流，获得地点线索或守卫情报。
3. 监控网络与广播（消耗数小时），获取地点、情报或物品资料。
4. 研究园区、军事检查站和地下实验室的剧情线索。
5. 潜入政府机构，取得机密地点与通行情报。

政府与机密地点没有硬性阶段门禁，但守卫会拦下没有权限的人：

- 反复接触守卫（跨循环累计 3 次）后可摸清换班规律潜入。
- 掌握关键情报后可直接交涉进入。
- 或者转入有权限的人类躯体。

地点物资按物品阶段更新：前期只有普通物资，后期才会出现超凡材料与法器。

## 自动决策

遇到敌人时优先治疗、逃跑或战斗。没有敌人时依次处理：

1. 解剖可解剖的尸体（仅在有意识后）。
2. 感染、伤势、饥饿、口渴、尿意、便意、疲倦。
3. 搜索当前地点。

当前地点搜索耗尽后，前往还有搜索次数且危险度合适的地点；没有新地点可去时，监控网络或侦察周边。有人且可潜入的地点会优先走通风口、后门或消防通道。

## 战斗

- 行动面板默认停在「攻击」，用 `[←/→]` 在攻击、施法、道具之间切换，`[↑/↓]` 选择，`[Enter]` 执行，`[f]`/`[Esc]` 逃跑，`[q]` 保存退出。
- 面板只列出**当前可用**的攻击、法术和道具；敌人的反击只写入日志。
- 法术消耗灵、法或魂；装备法杖会提高法术伤害。
- 生物掉落的不是成品装备，而是尸体材料。

## 错误与恢复

界面操作出错时会切换到错误信息屏幕。游戏内可以选择返回游戏继续当前进度、保存并退出到标题界面，或不保存直接退出；如果自动存档刚刚失败，则只提供返回与退出，避免反复失败。标题界面出错时可以返回标题或退出游戏。
